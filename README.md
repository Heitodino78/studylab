# StudyLab

Projeto em estágio inicial; ainda não é um aplicativo funcional. Requer Node 18 e npm. Quando o registro npm estiver acessível, execute `npm install`, `npm test` e `npm run build`. Nenhum dado de exemplo é incluído.

O cálculo SM-2 usa notas inteiras de 0 a 5. Notas inferiores a 3 reiniciam a sequência e agendam em um dia; sucessos usam intervalos de 1, 6 e depois o intervalo anterior multiplicado pelo fator de facilidade anterior. O fator é ajustado pela fórmula SM-2 e limitado a 1,3.
